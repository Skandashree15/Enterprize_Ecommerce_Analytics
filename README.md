# 📊 Financial Sales Data Analytics

##  Overview

An end-to-end **Financial Sales Data Analytics project** that transforms raw sales data into meaningful business insights using **Excel, SQL, Python, Google Colab, and Power BI**.

The project covers data cleaning, exploratory analysis, SQL-based business analysis, and interactive dashboard development to understand **sales, revenue, profit, product performance, customer trends, and regional performance**.

##  Tools & Technologies

* **Excel** – Data cleaning and preparation
* **SQL / MySQL** – Data querying and analysis
* **Python** – Data cleaning and exploratory data analysis
* **Google Colab** – Python-based analysis
* **Pandas, NumPy** – Data manipulation
* **Matplotlib, Seaborn** – Data visualization
* **Power BI** – Interactive dashboard and KPI visualization
* **GitHub** – Project documentation and version control

##  Project Workflow

```text
Raw Data
   ↓
Data Cleaning & Preparation
   ↓
Python EDA
   ↓
SQL Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights
```

## Key Analysis

* Sales and revenue performance
* Profit and profitability trends
* Product performance
* Customer analysis
* Regional sales analysis
* Time-based sales trends
* KPI analysis and visualization

## Power BI Dashboard

The interactive dashboard provides a consolidated view of key financial KPIs and allows users to explore sales and profitability across different products, customers, regions, and time periods using interactive filters and visualizations.

## Key Outcome

The project demonstrates the complete **Data Analyst workflow**, from preparing raw data and performing analytical queries to creating visual dashboards and deriving business-oriented insights for data-driven decision-making.
